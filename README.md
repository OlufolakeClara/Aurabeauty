# Aura Beauty — AI Skincare & Beauty Intelligence App

Live Website: https://aurabeautyappv7-2.vercel.app/

A browser-native beauty intelligence application that leverages on-device media capture and computer vision pipelines to analyze a user's skin profile and generate customized, interactive skincare protocols.

## 🛠️ Technical Features & Architecture
- **Browser-Native Vision Pipeline:** Integrated with browser hardware layers using the HTML5 MediaDevices API to capture real-time, high-fidelity user images for analysis.
- **AI Processing Engine:** Built a processing pipeline to parse visual characteristics and feed computer vision data into a personalized recommendation engine.
- **Guided Consultation Flow:** Features smooth, multi-step UX intake containers that balance user psychology with technical assessment steps.
- **Commerce Logic Layer:** Programmed a retail integration layer that dynamically maps skin analysis results into hyper-personalized product recommendation cards.

## 🧰 Technical Stack
- **Frontend Architecture:** Modern JavaScript Core, Semantic HTML5 Structures
- **Hardware Integration:** HTML5 MediaDevices API (Camera Streaming Integration)
- **Styling Framework:** Custom CSS Design Tokens & Responsive Layouts
- **Deployment Infrastructure:** Vercel Pipeline
